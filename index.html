PRZEWODNIK

Od katalogu do działającego agenta w 3 krokach

Skill to folder z plikiem SKILL.md. Ten sam format czytają Claude Code, Codex, Cursor, Gemini CLI, GitHub Copilot i dziesiątki innych agentów. Różnią się tylko foldery, w których go szukają.

01

Wybierz i sprawdź źródło

Otwórz kartę skilla, kliknij „Źródło" i przeczytaj cały SKILL.md. Zwróć uwagę na dołączone skrypty, allowed-tools i licencję upstream. Nasze znaczniki to wskazówki, nie certyfikat bezpieczeństwa.

Model zaufania →
02

Zainstaluj jedną komendą

Najpewniejsza forma wskazuje bezpośrednio na folder skilla — działa też w repozytoriach z zagnieżdżonymi pluginami. Wymaga Node.js 22.20+.

npx skills add https://github.com/anthropics/skills/tree/main/skills/pdf
npx skills add anthropics/skills --skill pdf -g -y
03

Bez Node.js: ręcznie

Sklonuj repozytorium i skopiuj folder skilla do katalogu agenta. Nazwa folderu musi zgadzać się z polem name w frontmatterze. Potem uruchom nową sesję agenta.

git clone --depth 1 https://github.com/anthropics/skills.git /tmp/skills
cp -r /tmp/skills/skills/pdf .agents/skills/pdf

Gdzie agent szuka skilli

CLI wykrywa zainstalowane agenty. Jeśli pracujesz w zespole na różnych narzędziach, wybierz wspólny katalog .agents/skills/.

Dane dla Twojego agenta

Katalog jest zwykłym plikiem JSON. Możesz go wczytać w skrypcie, w AGENTS.md albo zainstalować nasz skill-finder, żeby agent sam proponował skille.

python3 scripts/query_catalog.py search "security audit" --limit 5
python3 scripts/query_catalog.py install anthropics/skills/pdf
